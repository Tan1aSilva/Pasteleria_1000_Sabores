# Pasteleria_Mil_Sabores
Proyecto de e-commerce para la evaluación de desarrollo fullstack 2.

## Descripción
Sitio web de ventas online basado en caso "Pasteleria Mil Sabores" 
Desarrollado con HTML5, CSS3 y JavaScript, usando Bootstrap 5 como framework de diseño.

##Alcance de entrega
esta versión (V1) opera completamente en el navegador, no tiene backeend ni base de datos.
tanto pedidos como pagos son simulados. Los requisitos funcionales como administración interna(gestión de productos y usuarios)
esta planificado para las siguientes evaluaciones.

## Estructura del proyecto
-inicio - Pagina principal
-Visualización_catalogo - Catálogo de productos con filtros y búsqueda
-Funcionalidad_carrito - Carrito de compras
-Registro_autenticacion_usuario -Login, registro y perfil de usuario.
-Gestion_envios - Seguimiento de envíos
-Pro_seg_pedidos - Procesamiento y seguimiento de pedidos
